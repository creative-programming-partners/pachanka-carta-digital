# Fotos de los platos

Aquí van las fotos de la carta. **El nombre del archivo es el que manda**: la web
busca `assets/platos/<id-del-plato>.jpg` y, si no lo encuentra, deja el marcador
con la "P" y el texto "Foto próximamente". No hay que tocar código: basta con
subir la foto con el nombre correcto.

- Formato: **.jpg** (en minúsculas)
- Proporción recomendada: **16:10 horizontal** (la cartilla la muestra así)
- Tamaño recomendado: **1600 × 1000 px**, menos de 400 KB
- Si falta alguna, la carta sigue funcionando igual
